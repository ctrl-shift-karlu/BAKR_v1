### P1
1. **About video weight** — `public/video/dnsc-about-video.mp4` is 36.7 MB and is fetched twice on /about (74.8 MB transfer). Re-encode to ~2–4 MB (720p, H.264/WebM, ~15 s loop), lazy-attach `src` when in view.
2. **Home preloader blocks content** — `public/js/bakr-core.js:32` `MIN = 2900`, but `load` waits on heavy images, so it stays up to the 4.5 s fallback, on every visit (measured 4.5 s). Show once per session (like `bakrWelcomeSeen`) and hide on `DOMContentLoaded`, not `load`.
3. **Gold button contrast** — `.sa-btn-gold` (white on #b8912f) = 2.9:1 on studentLogin/studentRegister primary "Sign in"/"Create account"; `.bk-stack-seg` white on gold/green on About = 2.9 / 3.4:1; `.bk-msg-kicker` gold on white 2.9:1; auth brand subtitle #b8912f on #f6f5f2 = 2.7:1. `nx-btn-gold` dark-on-gold = 4.4:1 (just under). WCAG 1.4.3.
4. **No password recovery path** — studentLogin has no "Forgot password?" link; `/forgotPassword` is a static staff-styled page that sends nothing. A locked-out student has no route.
5. **Undersized UI text** — 26+ labels at 9–10.88 px (`.bakr-dnsc-image-tag` 9 px, `.nx-welcome-kicker` 9 px, `.nx-story-label` 10.88 px, `.sector-tag` 10.5 px, auth brand subtitle 10.24 px).
6. **Heavy raster** — `public/images/img/Dnsc.png` 1.48 MB (Home + Finder); 6 other JPGs 330–470 KB. Convert to WebP/AVIF, add `srcset`, `loading="lazy"` below the fold.

### P2
7. **Profile overflows on mobile** — "Redo or change answers" (`.sp-btn-sm` in profile header, resources/views/student/profile.blade.php) pushes page to 398 px and clips the avatar.
8. **Results page length** — all 11 cards render fully expanded (9,400 px desktop). Collapse checks/details for "Not a match right now" by default; on mobile the first result starts ~850 px down (profile card + nav + banner).
9. **Logged-in navbar** shows "Login As" instead of account/sign-out.
10. **Skipped headings** — /scholarships h1 → h5 ("Scholarship Shelf"), h2 → h4 (card titles); portal pages put the user-name h2 before the page h1.
11. **Small touch targets** — dashboard "Why?" 53x20, "View all" 71x21, footer links 21–22 px tall, "Back to home" 19 px, "Back to sign in" 15 px.
12. **Off-system pages** — `scholarshipFinder` uses its own floating navbar ("Feedback", no skip link) and footer; `forgotPassword` uses Inter, a blank logo tile, 2 × h1, no `<main>`.
13. **Weak focus ring** on Scholarships search (`bakr-scholarships.css:151-177`, 18% gold glow, inner outline removed). WCAG 2.4.7 / 1.4.11.
14. **Off-palette links** — "Why?" and "View all" on dashboard use default Bootstrap blue.

### P3
15. Muted text #7a756e on tinted backgrounds is 3.8–4.4:1 in several CTA strips (`.bk-cta-strip p`, `.bk-footer-cta p`).
16. Home logo link with no accessible name (`a` 163x20 in footer/brand area).
